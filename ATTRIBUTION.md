## Bundled baseline

`assets/base-pi-web-dark.css` is a byte-identical copy of the official PI WEB Dark
palette shipped with [`@jmfederico/pi-web`](https://www.npmjs.com/package/@jmfederico/pi-web)
version `1.202611.2` (MIT). It is bundled so plugins inherit their original palette
instead of the theme's core colours.
